# SimplePlane Desktop 0.3.0

Windows TUN 直连功能里程碑。

## 功能与修复

- Windows TUN 的 `direct` 规则使用物理网卡和原 DNS 建立真正的 IPv4 TCP 直连；代理规则继续通过所选节点出网。
- 默认 TUN 配置加入百度及相关资源域名的直连规则。其他域名是否直连取决于已有规则。
- 修复 FakeDNS 为网站分配 TUN 网卡、DNS 和网关地址的冲突。
- 修复 Windows TUN 网卡缺少 DNS 配置造成的系统解析失败。
- 修复 TUN 退出后把自动获取 DNS 错误恢复成手动 DNS；原来自动获取的接口继续保持自动获取。
- 启动脚本统一请求 UAC，改善普通权限下的启动流程。

## 验证记录

DNS 修复完成后，56 项 Rust 单元测试和 2 项集成测试通过，4 项环境相关测试跳过。已完成 Windows 真实 TUN 启停、DNS 自动获取状态恢复，以及百度直连和 Google 代理 HTTPS 访问验证。版本号调整已检查 Tauri、Cargo 与锁文件的一致性。

## 已知问题与范围

- 仍有 HTTP/3 节点连接间歇出现八秒超时的问题，根因尚未确认。本版本不宣称解决该故障。
- 新增直连出口覆盖 Windows IPv4 TCP；普通 UDP 转发、IPv6 直连和物理网卡自动切换不在本次范围。切换物理网络后需重连 TUN。
- 安卓端及 proxy-remote 的 UDP 功能未包含在本次里程碑分支。

正式安装包应从合并后的发布提交重新构建，并通过发布流水线验证。
