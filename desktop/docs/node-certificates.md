# 在桌面端添加 HTTP/3 节点

1. 在「代理配置」点击「添加」，填写节点地址、端口、加密方式和密钥。
2. 「证书服务器名称」留空时使用节点 Host。如果连接的是 IP，但证书签给某个域名，填写证书对应的域名。
3. 服务端使用自签名证书或私有 CA 时，点击「导入证书」，选择管理员提供的 PEM 格式公开证书（`.pem`、`.crt` 或 `.cer`）。不要选择服务端私钥。
4. 选择「使用此节点」，点击「保存配置」，查看运行时节点状态。处于 TUN 模式时，新增地址仍需先断开再保存。

证书会复制到应用配置目录下的 `certificates` 文件夹，不依赖原文件的位置。再次导入可替换该节点的证书，保存后会触发配置更新。点击「清除」可移除自定义信任证书，改用系统信任；已有的高级证书指纹配置仍会保留。

以 `20.78.53.111` 为例：填写地址和 9090 端口，证书服务器名称留空，导入该服务器的公开证书后保存即可。不要使用 `54.172.101.190` 的名称或独立自签名证书。

老节点已有的 TLS 配置会显示在页面中，可直接修改；新节点的名称与证书字段为空，不会继承其他节点的身份。HTTP/2 节点不显示这组 HTTP/3 设置。
