# 自动切换规格与验收约束

详细设计以 [P3/P4 方案](../../design/http3-auto-failover-p3-p4.md) 为准，实施项见 [tasks.md](tasks.md)，实测记录见 [verification.md](verification.md)。

- 自动模式加载固定 HTTP/3 节点列表，每节点一条预连接，ClusterInvoker 同时只选择一个业务节点。
- 每个 Invoker 绑定 nodeId，stream 绑定具体 Invoker；DATA、DISCONNECT 不重新选节点，不重放业务。
- 启动首选，故障后随机选择未熔断且可用的备用；当前健康就保持，恢复不抢回首选。
- 切换暂停新流，沿用 retireBindings，按旧 nodeId 关闭旧 client，再启用下一节点；其他备用连接保留。
- 故障计数按节点独立，网站错误不计节点故障，新节点有宽限，恢复必须经过冷却与受控检查。
- 自动转手动复用配置监听和退出路径，ClusterInvoker 最终仅保留所选节点；手动模式不自动回退。
- 自动节点列表与连接参数修改重启生效，模式和手动选择可监听；运行时当前节点不写回用户偏好。
- Web、桌面、配置生成、运行状态的模式和首选语义一致，保留旧配置、HTTP/2 与 TLS 校验。

验收必须分别提供单元、集成、真实双机、资源释放、性能与客户端构建证据；未执行或失败的项目明确保留，不能用另一层测试代替。
