## 真实双机测试

脚本：[test-auto-failover-remote.py](../../../scripts/test-auto-failover-remote.py)。它临时停止测试服务并在每轮及退出时恢复，输入凭据与证书放在忽略的 .build 目录，不进入仓库。

临时测试目录需提供 nodes.private.json（a/b 节点配置）、targets.json（每台机器临时回显服务的 host、port）、对应 SSH 密钥与已验证的 known_hosts；脚本默认匹配本次两台测试节点。运行示例：

```sh
python3 scripts/test-auto-failover-remote.py --cycles 20
```

记录包括明文 HTTP 出口身份、CONNECT 回显、SOCKS5、校验证书的 HTTPS、网站拒绝不熔断、故障切换、恢复不抢回、全节点不可用快速失败、自动转手动和性能对照。

测试客户端的 QUIC idleTimeoutMs 设为 7000，断连确认仍为正式策略的 5000 毫秒；因此当前观测约 12.5 秒不能代表默认 60 秒 QUIC 空闲配置的恢复速度。突发 UDP 进程退出可能先表现为黑洞，发现故障的时间必须与确认后的切换时间分开说明。

性能样本是同节点手动/自动模式的 64 KiB 回显往返，当前各 8 次，存在网络波动和预热差异，只作原始对照，不据此承诺无性能损失。
