# 自动切换实施与验收清单

规格依据：[P3/P4 设计](../../design/http3-auto-failover-p3-p4.md)。以下项目只有取得测试证据后才标记完成。

| 编号 | 要求与实施任务 | 验证证据 | 状态 |
|---|---|---|---|
| AF-01 | manual/auto 配置、有效首选、稳定 nodeId、单连接约束 | 配置单测及旧配置迁移回归 | 实施中 |
| AF-02 | 全节点预连接、ClusterInvoker 持有当前节点、随机健康备用、不逐流轮换 | 集群单测、连接集成测试 | 待实施 |
| AF-03 | 断连确认、独立检查、宽限、驻留、OPEN/HALF_OPEN 恢复和退避 | 可控时钟单测、故障集成测试 | 待实施 |
| AF-04 | 沿用全量绑定清理，仅关闭旧 client，不影响其他预连接 | 流生命周期及关闭集成测试 | 待实施 |
| AF-05 | 监听手动选择和模式变化，自动转手动仅留目标，自动列表修改重启生效 | 监听器及模式转换测试 | 待实施 |
| AF-06 | Web/桌面模式、首选、实际当前节点、状态和版本语义 | 前后端测试、构建及界面验证 | 待实施 |
| AF-07 | 双机真实代理、停止恢复、至少 20 轮切换、性能和资源对照 | 54.172.101.190 / 20.78.53.111 实测记录 | 待实施 |
| AF-08 | HTTP CONNECT/SOCKS5/TLS/TUN、手动和 HTTP/2 回归、桌面构建 | 完整测试报告及构建记录 | 待实施 |

不改协议、加密和业务请求重试语义，不实现自动节点热增删。测试报告单独记录命令、版本、通过/失败/跳过及未验证项目，不把文档或编译成功当成全链路成功。
