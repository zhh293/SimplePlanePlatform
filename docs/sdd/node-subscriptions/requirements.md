# 账号授权、扫码与节点订阅需求

2026-11-23。SimplePlane 基线 `60a1c18`，AuthSystemSimple 基线 `e1d8fc0`。用户授权实现并进行远端灰度。开发顺序为需求、设计、任务、实现、验证。下列编号贯穿两个系统。

| ID | 可观察的验收条件 |
|---|---|
| SUB-01 | 在尚未连接代理的新设备上，用户可以通过系统浏览器在既有 AuthSystemSimple 登录。管理服务用已验证的 issuer 和 subject 标识用户。客户端安装包中没有 OIDC 客户端秘密。取消、过期和身份不匹配均不创建授权。 |
| SUB-02 | 桌面显示短时二维码和可核对的短码。手机登录后显示申请设备、匹配短码并要求明确确认。只有发起设备可以兑换，重复扫码、并发兑换、超时和拒绝均不能多绑定一台。桌面和 Android 支持同机浏览器流程。 |
| SUB-03 | 管理员可以开通、变更和撤回账号对应的节点组、到期时间、设备上限。普通用户只能查看或解绑自己的设备。在并发注册和重试下也须执行名额限制。 |
| SUB-04 | 桌面和 Android 自动同步稳定节点 ID、地址、协议、TLS 服务名及公开信任材料，显示授权来源；重复同步不重复建节点。失败保留上次完整快照，成功的空清单移除该订阅的节点。手动节点、本地偏好及其他账号的状态隔离。 |
| SUB-05 | 已授权设备能通过实际代理建立 TCP 和 UDP 业务流；复制清单、仅持有共享密钥、跨组或跨节点使用凭证均不能使用受保护入口。密钥生成和持钥证明在设备侧完成。 |
| SUB-06 | 账号到期、设备解绑、撤权后拒绝重新领证。旧凭证限制在明确的有效窗口内；已有连接和空闲后再用的连接在窗口结束前关闭。过期、错误签名和错误信任域拒绝接入。 |
| SUB-07 | 设备私钥受操作系统保护；二维码、配置导出、日志、构建物和验收证据不能泄漏私钥、兑换秘密或刷新令牌。控制服务不可用时拒绝发新凭证，节点验签不逐包请求控制服务。 |
| SUB-08 | 远端独立入口与测试账户完成真实登录、扫码、同步、浏览器同机路径、TCP/UDP 转发、拒绝和撤销测试。记录版本、时间、真实客户端、节点标识及清理结果。手动节点和正式服务做前后对照，未实测的客户端单独列出。 |

首版由管理员授予权益，支付不是本轮需求。长期共享订阅链接不能作为持有设备的证明。

用户补充：只有公网 IP。SUB-01/SUB-08 的浏览器入口须以公网 IP 访问，通过系统信任链与 IP SAN 校验，并验证证书自动续期和加载。

2026-11-23 进一步确认：当前无已有 IP 证书，用户明确暂不申请公网证书。远端灰度以测试 CA、IP SAN 和隔离测试客户端信任完成，保留正常的 TLS 验证。公开受信入口及其续期验收延期，不能用私有 CA 灰度替代正式可用性结论。

用户要求优先执行现有环境可做的测试，避免占用存储。Android SDK、NDK、模拟器和真机用例延期。本轮记录实际桌面二维码、真实浏览器及共享网络核心的覆盖范围。

2026-11-24，运营方确认普通手机的安装交付物只有 APK。SUB-01/SUB-04/SUB-08 的验收从仅含系统默认信任根的设备开始。用户只需登录并确认设备，客户端自动拉取节点配置及节点证书材料。入口证书的部署、更新、加载由服务端负责。验收需分别核实首次登录、配置下发及实际节点连通性。运营方的专用浏览器和私有 CA 测试包只用于隔离验证。
