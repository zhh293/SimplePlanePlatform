# 桌面 0.3.4 发布

| 要求 | 验收 |
| --- | --- |
| 升版与可追溯构建 | Tauri、Cargo 和锁文件统一为 0.3.4。GitHub 标签 `v0.3.4` 指向已经推送的源码提交。 |
| 构建并提供安装包 | GitHub Actions 在 Windows x64 和 macOS arm64 构建桌面客户端。发行版提供安装包和两种平台的签名更新包。 |
| 让现有客户端发现更新 | 将同一对已验签的更新包发布到当前客户端配置的更新服务。以 0.3.3 请求 Windows 和 macOS 接口均返回 0.3.4，以 0.3.4 请求均返回 204。 |
| 下载完整性 | 使用客户端内置公钥验证更新包签名，并比对更新服务下载结果与 GitHub 产物的 SHA-256。 |

桌面客户端发现更新后显示版本提示，用户确认后由内置更新器下载、验签与安装。验证阶段保留当前安装和用户配置。
