# 桌面 0.3.4 发布

| 要求 | 验收 |
| --- | --- |
| 升版与可追溯构建 | Tauri、Cargo 和锁文件统一为 0.3.4。GitHub 标签 `v0.3.4` 指向已经推送的源码提交。 |
| 构建并提供安装包 | GitHub Actions 在 Windows x64 和 macOS arm64 构建桌面客户端。发行版提供安装包和两种平台的签名更新包。 |
| 让现有客户端发现更新 | 将同一对已验签的更新包发布到当前客户端配置的更新服务。以 0.3.3 请求 Windows 和 macOS 接口均返回 0.3.4，以 0.3.4 请求均返回 204。 |
| 下载完整性 | 从更新清单列出的地址取得更新包，以客户端内置公钥验签，并比对 GitHub 产物的 SHA-256。 |

桌面客户端发现更新后显示版本提示，用户确认后由内置更新器下载、验签与安装。验证阶段保留当前安装和用户配置。

更新主机的大文件传输反复断开时，允许版本表为经过验签的安装包记录 GitHub Releases 来源。更新服务继续提供两个平台的版本和签名信息，下载地址固定来自本项目、对应版本标签下的正式资产。原有本地安装包和下载接口继续可用。

## 发布验收

- `v0.3.4` 由提交 `b3c7362` 构建。Windows x64 与 macOS arm64 任务均通过。GitHub 发布页提供 Windows NSIS、MSI、macOS DMG 及对应的自动更新资产。[正式构建记录](https://github.com/zhh293/SimplePlanePlatform/actions/runs/45394469760) · [v0.3.4 发布页](https://github.com/zhh293/SimplePlanePlatform/releases/tag/v0.3.4)
- 两个更新包以现有客户端内置的 Minisign 公钥验签。自托管更新源对两个平台的 `0.3.3` 请求均返回 `0.3.4` 和对应签名，返回的官方下载地址可访问，版本和 SHA-256 与发布资产一致。两个平台请求 `0.3.4` 都得到 HTTP 204。
- 更新服务完整运行 132 项测试，包括不含本地安装包的 GitHub 来源和原有本地文件接口。部署前保存了代码与 SQLite 快照 `/opt/simpleplane-update/backups/desktop-034-20261124-210542`。
