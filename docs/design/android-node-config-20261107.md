# Android 0.1.5：节点选择与配置文件

日期：2026-11-07。基于 Android 0.1.4，版本更新为 `0.1.5` / versionCode `6`。

## 行为变化

- 首页可选择自动模式或指定节点。自动模式按顺序使用启用节点；手动模式仅将所选节点交给原生核心。VPN 运行期间不可更换节点。
- 删除所选节点后回到自动模式；删除它之前的节点时调整索引，继续指向原来的节点。导入和连接前校验节点是否存在、是否启用。
- 设置页通过 Android 系统文件选择器导入 JSON / 桌面 YAML，或保存 JSON 备份，无需申请通用存储权限。导入先展示节点、规则数量和连接选择，确认后替换配置。
- 文件读写放到 IO 调度器；限制为 256 KiB，拒绝非法 UTF-8，支持 UTF-8 BOM。文件读取失败或配置不合法时保留原配置。
- JSON 备份包含所有节点、停用状态、证书、MTU 配置值、路由规则和节点选择。未修改的导入规则保持原有顺序；文本导出也改为完整 JSON。MTU 值保留属于配置往返改进，不表示本次改变了 TUN 的 MTU 设置方式。
- 导入无节点或无关的文件时报告错误；解析 YAML 注释时保留密钥字符串中的 `#`。
- 页面重建时保存节点选择、导入规则顺序、MTU 配置值和等待文件选择器返回的导出内容。

备份包含密钥，界面已提示用户妥善保管。手动选择在断开后生效，不迁移已经建立的连接。
